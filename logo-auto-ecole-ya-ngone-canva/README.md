# Logo officiel — Auto École Ya Ngoné

## Référence verrouillée

Ce pack corrige l’ancienne déclinaison et reprend directement le logo validé :

- grand volant placé derrière le livre ;
- cercle central conservé ;
- livre ouvert avec deux grandes pages jaunes ;
- doubles contours inférieurs du livre ;
- texte exact : « AUTO ÉCOLE / YA NGONÉ » ;
- proportions et disposition du modèle de référence.

Le fichier à considérer comme référence absolue est :

`reference/REFERENCE_VALIDEE_NE_PAS_MODIFIER.png`

## Fichiers recommandés

- Site sur fond clair : `png/logo-horizontal-transparent-1600.png`
- Site sur fond bleu nuit : `png/logo-horizontal-inverse-transparent-1600.png`
- Import dans Canva : `svg/logo-horizontal.svg`
- Photo de profil : `png/photo-profil-fond-ivoire-1080.png`
- Symbole seul : `png/logo-symbole-transparent-1024.png`
- Favicon : dossier `favicon/`

## Organisation

### `png/`

Versions horizontales, symbole, profil et version verticale. Les fichiers
portant le mot `transparent` peuvent être posés sur un autre fond.

### `svg/`

Versions vectorisées à partir du master validé. Le texte est converti en
contours : aucune police n’est nécessaire et Canva ne peut pas remplacer
accidentellement la typographie.

### `favicon/`

Tailles 16, 32, 48, 180, 192 et 512 px, fichier `.ico`, SVG et icônes
Android/Apple.

### `reference/`

Image originale validée et master détouré. Ne pas modifier ces fichiers.

## Couleurs

- Bleu nuit : `#061532`
- Jaune : `#FBDE26`
- Ivoire : `#FDF9EB`

## Règles

1. Ne jamais redessiner séparément le livre ou le volant.
2. Ne jamais réduire le volant à un petit pictogramme posé au-dessus du livre.
3. Ne jamais modifier l’épaisseur ou la position du volant.
4. Ne jamais supprimer les doubles contours du livre.
5. Ne jamais étirer le logo horizontalement ou verticalement.
6. Utiliser la version inversée uniquement sur un fond sombre.
7. Conserver autour du logo une marge au moins égale au diamètre du cercle central.
