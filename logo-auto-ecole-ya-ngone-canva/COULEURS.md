# Couleurs officielles

| Usage | HEX | RGB |
|---|---:|---:|
| Bleu nuit principal | `#061532` | `6, 21, 50` |
| Jaune principal | `#FBDE26` | `251, 222, 38` |
| Ivoire | `#FDF9EB` | `253, 249, 235` |

La version officielle sur fond clair utilise le bleu nuit et le jaune.  
La version sur fond sombre remplace uniquement le bleu nuit par l’ivoire ; les
formes et les proportions restent identiques.
